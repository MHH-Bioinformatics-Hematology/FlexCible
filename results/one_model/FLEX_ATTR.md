# Release candidate all12one_fullrd against all12one: flexible input, Shapley values, attribution, group importance

Registry section 96. All numbers are medians over the 413 Akita test regions of the per-region Pearson r of log O/E (flexible input), or as stated. Complete tables, including every cell, bin size, quartile, range and test: `FLEX_ATTR_tables.md` (generated by `scripts/one_model_flex_attr.py`) and the csv files `flex_attr_*.csv` next to this file. Names: `all12one` = plain one model (sections 87, 90); `fullrd_meth` = all12one_fullrd with the cell's methylation track given in every mark set (14 tracks); `fullrd_nometh` = all12one_fullrd with Meth absent, i.e. the 13-mark design of section 87 (same 5876 set-by-consensus combinations, same random draws, same regions, same cells).

## Design and choices

- Same commands, cells and sets as sections 87 and 90, with the checkpoint-best of `all12one_fullrd_<k>kb`: `scripts/flexible_inputs.py` (new options `--model`, `--meth`), `scripts/attribute.py` (new options `--model`, `--meth`), `scripts/scale_importance.py` (new group "methylation", option `--exclude-cells`). `subsets.json` is byte-identical to that of section 87.
- Meth in the flexible-input sweep: the 13 marks remain the players (the mark sets, the draws and the Shapley design are those of section 87). In `fullrd_meth` the cell's methylation track is added to every set, including the empty set, so that "no marks" means "Meth only". In `fullrd_nometh` Meth is set absent in every set. Meth is a genome-wide track that exists for K562, HMEC, GM12878 and IMR-90; HUVEC has none, so for HUVEC the two variants are the same input and give identical numbers (a check of the pipeline). The marginal value of Meth is the paired difference v(set + Meth) - v(set) over the 271 sets per cell and bin size.
- Cohesin: the release model has a cohesin-fraction row; all cells are intact (1.0), and the cohesin-unknown indicator is not part of this model. In the attribution the cohesin-fraction row is a context row, held at its input value in the baseline (no attribution).
- Attribution: K562 at 10 kb, the same three windows (chr3:136605696-137654272, chr14:24182784-25231360, chr10:16289792-17338368), the same 40 random global regions (seed 0), 50 steps and, as the completeness check, 300 steps. With Meth (`fullrd_meth`, Meth is an attributed row, baseline = absent value) and with Meth set absent (`fullrd_nometh`, row attribution 0). The 13-mark shares of the two runs are therefore directly comparable with section 90, with the caveat that the shares of `fullrd_meth` are divided over 14 tracks.
- Group importance: the manuscript's Supplementary Fig. S9 was produced by `scripts/scale_importance.py` on the multi-resolution model A (`all12multires`, registry section on analysis C, `results/scale_importance/`), not on all12one. For a like-for-like comparison the script was run on all12one and on all12one_fullrd, on the disjoint test windows of the 12 cell lines (the depleted hct116_auxin sample of the release cache is excluded; 3540, 3732, 3732, 8760 windows at 25, 10, 5, 2 kb). The three result sets are in `results/scale_importance/`, `results/scale_importance_all12one/`, `results/scale_importance_all12one_fullrd/`. The group-importance figure script reads `scale_importance/importance_drop.csv`; the switch to the release model is one path (`scale_importance_all12one_fullrd`). Note that Fig. 8d/e of the manuscript (`imp_a`, `imp_b`) and the Shapley panels read `flexible_inputs/summary.csv` (and `per_region*.csv`) and the attribution panels read `attribution/ig_*`; the switch is `flexible_inputs/all12one_fullrd` (13 marks plus Meth) or `flexible_inputs/all12one_fullrd/nometh`, and `attribution/all12one_fullrd[/nometh]`.

The locus targets are within 0.8 per cent at 50 steps. The 300-step runs are in `s300/`.

## 6. Group importance (loss of the median per-window Pearson r when a group is set absent; test windows of the 12 cell lines)

Loss, 10 kb (the full tables for 2, 5, 10, 25 kb are in `FLEX_ATTR_tables.md`):

| group | model A (all12multires, Fig. S9) | all12one | all12one_fullrd |
|---|---|---|---|
| reference map | 0.313 | 0.307 | 0.098 |
| sequence (GC, CpG) | 0.090 | 0.163 | 0.196 |
| active | 0.115 | 0.010 | 0.008 |
| CTCF | 0.039 | 0.0015 | 0.0021 |
| cohesin | 0.042 | 0.0000 | 0.0017 |
| repressive | 0.031 | 0.0023 | 0.0013 |
| gene body | 0.022 | 0.0007 | 0.0012 |
| methylation | | | 0.0006 |
| motifs | 0.000 | 0.0001 | 0.0004 |

Score with all inputs (10 kb): 0.924, 0.920, 0.916. Ordering at 25, 10, 5, 2 kb for the release model: reference map (0.116, 0.098, 0.101, 0.118) and sequence (0.224, 0.196, 0.173, 0.163) first, then the active marks (0.010, 0.008, 0.016, 0.013), then group losses below 0.003 (CTCF, cohesin, repressive, gene body, methylation, motifs in changing order). The same ordering holds for all12one except that the reference map comes first (0.345, 0.307, 0.297, 0.296) before sequence (0.156 to 0.254). Model A ranked the reference map (0.28 to 0.35) before the active marks (0.10 to 0.12), sequence (0.07 to 0.11), cohesin (0.03 to 0.10) and CTCF (0.03 to 0.04). The two one-model checkpoints keep the reference map first (all12one) and the active marks ahead of the biological groups, but the sizes of CTCF, cohesin, repressive and gene-body losses are one to two orders of magnitude smaller in both one-model checkpoints than in model A: with track dropout over the marks (uniform_count, 0.5) the one model has learned to replace any single group by the others. The reference dropout lowers the reference-map loss to about a third (0.098 against 0.307 at 10 kb) because the model no longer depends on the plane, and Meth costs 0.0005 to 0.0014 when removed. The sequence group is dropped by setting GC and CpG to a raw-zero value, which is outside the range of real genomes, so its loss measures the sensitivity to an implausible input rather than the information of the group.

## Statements the manuscript can keep and statements that change

- Keep: the curve flattens after three to four marks with the consensus; the seven-mark set is within 0.021 of all 13 marks; CTCF and the cohesin subunits lead the Shapley values without consensus; the first-ranked attributed tracks are cohesin subunits and the consensus.
- Change if the figures are switched to the release model: the consensus-independent numbers (no mark without consensus 0.46 to 0.63, all 13 marks 0.67 to 0.88); the Shapley values without consensus are about half (CTCF 0.078 against 0.169); the attribution shares of the consensus fall to 0.17 to 0.20 and anchor enrichment to 2.5 to 3.9 times; the sizes of the group losses of Fig. S9 (CTCF, cohesin 0.002 instead of 0.04). The sentence "setting it absent costs 0.28 to 0.35 (reference map), the active marks 0.10 to 0.12, cohesin 0.03 to 0.10 and CTCF 0.03 to 0.04" describes model A and does not describe either one-model checkpoint.

## Not done, limits

- One run per checkpoint, no seed spread; three held-out cells; HMEC and HUVEC lack RAD21 and SMC3 (as in section 87); HUVEC has no methylation track.
- 5 kb and 2 kb use the small programme (K562, GM12878) as in section 87. The 2 kb sweep with Meth had to be rerun with set batch 6 after an out-of-memory error with six concurrent processes.
- Shapley bootstrap intervals use 200 resamples here (500 in the manuscript script); the point values are those of the same estimator.
- The cohesin-depleted use (cohesin fraction below 1) was not part of these analyses.
